== Description ==

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/unstoppable-lms/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to **Unstoppable LMS → Courses** to create your first course
4. Add lessons using the Course Builder
5. Enroll students and track their progress

== Frequently Asked Questions ==

= Is this really free? =

Yes! The free version is designed for single-course sites, pilots, and testing your workflow. It includes one course with up to 5 lessons — perfect for mini-courses or getting started. Pro removes all limits and adds advanced features like gradebook, discussions, and cohorts.

= Can I upgrade to Pro later? =

Absolutely. Your existing courses and data remain intact when you upgrade. Just purchase Pro, enter your license key, and all Pro features activate instantly.

= Does it work with caching plugins? =

Yes! Unstoppable LMS is built to work with caching, unlike other LMS plugins that have constant conflicts.

= Can I migrate from LearnDash? =

Yes, Pro includes a one-click migration tool that transfers your courses, lessons, students, enrollments, and progress data from LearnDash.

= What's the difference between Free and Pro gradebook? =

Free tracks basic completion (done/not done). Pro gives you the full gradebook schools need: points (13/15), percentages (86.7%), letter grades (A+, B-, etc.), GPA calculation, weighted averages, manual grade entry, and CSV export.

= What are Cohorts? =

Cohorts (Pro feature) let you reuse course content for multiple classes or terms. Create "Biology 101 - Fall 2025" and "Biology 101 - Spring 2026" using the same lessons, but with separate student groups, progress, grades, and discussions. Essential for schools with recurring classes.

= Do I need any other plugins? =

No. Unstoppable LMS is a complete solution. You don't need separate add-ons for gradebooks, forums, or other features — they're all included in Pro.

= Is my data safe? =

Yes. All data stays on your server. We don't send student data anywhere. The only external connection in Pro is for license validation and updates.
